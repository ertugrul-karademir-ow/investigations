Provisioning chain

Dapr enabled and/or Atlas access configured
  → application_workload_namespaces
  → one Azure managed identity per namespace
  → exact OIDC federated subject
  → Service Bus role and/or Atlas workload user
  → Terraform-generated Argo CD values
  → namespace chart
  → annotated application-sa

Runtime chain

Pod serviceAccountName: application-sa
  + Pod label azure.workload.identity/use: "true"
  → projected Kubernetes token
  → Entra OIDC exchange
  → managed identity access token
  → Service Bus or Atlas authorization

Boundary check: the ServiceAccount annotation chooses an Azure identity; it does not grant that identity permissions. The Pod label triggers token projection; it does not select the ServiceAccount. Kubernetes RBAC and external-service authorization remain separate.
