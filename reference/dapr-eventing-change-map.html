Compute event lane

compute tier
  → default_events_tier (testing | staging | prod)
  → tier-scoped Service Bus namespace
  → managed identity shared by opted-in namespaces
  → Dapr pub/sub Component
  → topics and consumer subscriptions

Data event lane

data environment
  → dedicated Service Bus namespace
  → Terraform-created fabric-data-etl topic
  → Databricks send-only connection string
  → data-environment Dapr identity
  → application subscriber

Identity chain

Pod using dapr-enabled-sa
  → projected Kubernetes service-account token
  → AKS OIDC issuer
  → federated identity credential
  → user-assigned managed identity
  → custom DAPR Service Bus role
  → Azure Service Bus namespace
Boundary check: Dapr is not the broker. It is the application-facing runtime and adapter; Azure Service Bus stores and fans out messages. This repository builds the platform side, but does not show the final application Component, sidecar annotations, topic contracts, or handler routes.
