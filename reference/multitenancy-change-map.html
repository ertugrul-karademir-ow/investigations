Invariant checklist

same tenant key at every hop
database user scoped readWrite to one tenant DB
common DB selected only through explicit common accessor
header accepted only after user authorization
tenant config cannot contain another tenant's values
jobs, events, queues, and callbacks preserve tenant context
missing context fails closed in multitenant mode
Do not confuse identifiers: the tenant key routes application work; the banner code selects the corresponding retail data; the namespace identifies a product environment; the client identifies the outer infrastructure boundary.
